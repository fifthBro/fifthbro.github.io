Overview

Turns the digital instrument cluster on Porsche PCM5 / VW / Audi MH2P into a proper second navigation display driven by your phone — both Android Auto and CarPlay. Live map view, turn-by-turn arrows on the physical dial, seamless handoff back to native Porsche navigation when the phone disconnects.

✅ Status: Stable release — CarPlay cluster rendering now live alongside Android Auto.

What it does

  • CarPlay cluster nav — Apple Maps, Google Maps, Waze, whatever iPhone is running gets pushed to the digital cluster in real time
  • Android Auto cluster nav — Google Maps, Waze, other AA-compatible apps mirror live to the cluster
  • Turn-by-turn on the physical dial — maneuver icons, distance, lane guidance, roundabout exits, for both platforms
  • Native maps come back cleanly — when the phone disconnects, Porsche's built-in navigation reclaims the cluster automatically
  • HMI-independent — leave the main head-unit screen on native infotainment; the cluster keeps showing phone nav
  • Session-stable — reconnects, park/drive cycles, HMI-off transitions all handled without the mirror dying
  • Intercepts Android Auto navigation events via DSI, CarPlay navigation via RGI
  • Second video stream (H.264 via NvMedia) decoded on the head unit and composited on the cluster's dedicated video surface
  • Heartbeat-based override so the display holds against native nav re-writes
  • Supports Google Maps, Waze, Apple Maps, and other third-party nav apps

Installation

Based on MH2p Mod Kit

⚠️ Warning: This modifies files on your PCM5 / MH2P unit. Only proceed if you understand the risks. Uninstall is reversible.

Prerequisites

  • Car with PCM5 / MH2P head unit
  • SD card (FAT32)
  • Android Auto or CarPlay compatible phone

Steps

  • Download the latest release
  • Format the SD card as FAT32
  • Extract the ZIP to the root of the SD card
  • Start the vehicle
  • Insert the SD card
  • Within a few seconds, the head unit will reboot
  • The update installs automatically
  • When done, a prompt says "Please remove update media"
  • Remove the SD card from the vehicle
  • Head unit reboots into normal mode with the mod installed

Uninstall

  • On the SD card, rename uninstall.txt.template to uninstall.txt
  • Re-run the ModKit update procedure with the SD card
  • Update/uninstall.sh runs automatically and restores originals from backup
  • Remove uninstall.txt from the SD card afterwards so it doesn't re-trigger on the next boot

Architecture

ClusterIntegration bridges the Android Auto DSI event stream and the CarPlay RGI event stream to the Porsche instrument cluster BAP navigation protocol, plus a second video stream from the phone that is decoded on the head unit and composited to the cluster's dedicated video surface.

Data Flow

Phone (Android Auto or CarPlay)
        ↓
    Nav events (DSI / RGI)      +    H.264 video stream
        ↓                                    ↓
ClusterIntegration               Cluster daemon
    ├─ event → BAP maneuver          ├─ NvMedia H.264 decode
    ├─ heartbeat (every 2s)          ├─ YV12 → RGBA
    └─ CombiBAPServiceNavi           └─ Cluster video window
        ↓                                    ↓
Instrument Cluster (arrow dial + video display)

AA / CarPlay Event → BAP Maneuver Translation

Maps eventCode (1–19) + turnSide + angle + num to a BAP maneuver descriptor.
Direction is a 0–255 byte (0=straight, 64=left/90°, 128=back/180°, 192=right/270°).

Event(s)Translation
event=3–5 (turns)TURN, direction from angle or fallback to turnSide
event=6 (U-turn)UTURN
event=7 (on-ramp)TURN_ON_MAINROAD, direction from turnSide
event=8/10 (off-ramp/merge)EXIT_LEFT or EXIT_RIGHT based on turnSide; side=0 → FOLLOW_STREET
event=9 (fork)FORK_2
event=14 (STRAIGHT/KEEP)num==1 = Waze lane-keep → FOLLOW_STREET; num==0 or num>1 = motorway exit → EXIT_LEFT/RIGHT
event=11–13 (roundabout)ROUNDABOUT_TRS_LEFT/RIGHT.
RHD angle correction: (540−angle)%360;
LHD: (angle+180)%360.
T-junction override: 180° → 0° when exit ≤ 2
event=16/17 (ferry)FERRY
event=19 (destination preview)Sets flag, falls through as FOLLOW_STREET. DESTINATION symbol shown only on event=0 valid=2

Distance Update Pipeline

  1. Throttle check — minimum ms between sends per proximity zone (veryFar=2000ms down to now=100ms).
  2. Maneuver change detection — key = road|eventCode|turnSide. New maneuver resets baseline distance and bypasses throttle for first update.
  3. Distance threshold — minimum change required per zone (100m at veryFar down to 5m at now).
  4. Unit conversion — metric: m below 100m, tenths of km to 19.9km. Imperial: yards below 161m, tenths of miles to 9.9mi.
  5. Bargraph — (1 − distance/maneuverInitialDistance) × 100, clamped 0–100.
  6. Roundabout traversal — force distance/bargraph to 0 during CONTINUE events to suppress erratic display inside roundabouts.

Heartbeat

A daemon timer fires every heartbeatInterval ms (default 2000ms) while navigation is active. It resends the last cached maneuver, distance, bargraph, and destination data to continuously override the cluster's native navigation display.

Logging

Two parallel log files: plain (full road names) and hashed (road names, music metadata replaced with [HASH_nnn] for privacy).
Each entry has a dual timestamp: QNX boot time + real car clock.
When enableExternalLogging=true, logs are written to USB/SD if writable, with automatic fallback to /tmp.

Configuration

The config file cluster_config.json is installed on the head unit. To override without reinstalling, place a file on a USB stick or SD card — the app checks these paths first:

/fs/usb0_0/cluster_config.json
/fs/usb1_0/cluster_config.json
/fs/sda0/cluster_config.json
/fs/sdb0/cluster_config.json

Dynamic Thresholds

Scope of the project

Two years of evenings and weekends. Reverse engineering of the QNX Screen API, NvMedia decoder, iAP2 protocol, Android Auto and CarPlay wire protocols, Porsche's BAP cluster protocol, and the composition stack on both PCM5 and MHI2 head units.

Rough labor equivalent at specialist embedded / reverse-engineering contractor rates: $90k–$200k. For an automotive middleware vendor doing this cleanly with docs and full test rig: $250k–$400k. What an OEM would price this at as a factory feature: $500–$2000 per vehicle.

This project is free. None of that value is going anywhere except back into more releases.

If someone is asking you for money for a cluster mod built on this work, they got the underlying code for free too.

Contributing & Troubleshooting

This project is the result of extensive reverse-engineering and testing on MH2P. Contributions welcome via the ModKit Discord.

Troubleshooting / bug reports


Format a FAT32 SD card
Put the SD in the head unit before turning ignition on
Drive → afterwards when you turn ignition off → pull SD card → look in the log for the event that was wrong → match it to the same one in the hashed log (timestamps help)
Share the hashed logs + expected vs actual cluster behaviour on the Discord

Known limitations


RHD and metric/imperial coverage still expanding — report issues
Roundabout accuracy limited by what the phone sends (Waze in particular can lack exit angles)
Data granularity and update rate limit accuracy on very short maneuvers
Some glitches are inherent to Android Auto / CarPlay themselves
